# Telas

Interface do Controle de Demandas de Mudanças, em HTML, CSS e JavaScript puro. Funciona sem build e sem internet:
abra `index.html` em um navegador atual.

Esta pasta é a origem das telas. Depois de alterá-la, copie os arquivos para `src/main/resources/static/`.

Regras de negócio e organização do código: [docs/ESPECIFICACAO.md](../docs/ESPECIFICACAO.md).
